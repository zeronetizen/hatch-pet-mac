HatchPet Mac 版 v0.20：配置只认配对串，设置页砍掉三字段手填。

1. **当前连接改为只读展示**：设置页顶部的服务器/通道名/accesskey 三个输入框已删除，换成「当前连接」只读区——服务器与通道名纯文本展示，accesskey 只显示掩码 + 长度（例如「••••••••（32 字符，已存本机）」），不显示明文、不可编辑。
2. **换配置只能粘配对串**：粘贴 `hatchpet1:` 配对串点「应用配对串」，校验通过即写入并自动测连接，输入框随即清空不留明文；串不对只提示、不动现有连接。「复制配对串」「测试连接」「重新走引导」保留（测试连接测的是当前已保存生效的连接）。
3. **配置与数据不动**：砍的只是手填入口——已保存的服务器/通道/钥仍在原存储里（UserDefaults + 本机钥文件），与引导页同一套读写。本版升级后现有连接不断、轮询照常，无需重新配置。
4. **文案与协议对齐**：设置与引导中关于手填/兜底的说法已删，统一为「配置只认配对串」；PROTOCOL.md 的 Pairing 节同步更新。

其余功能不变（首启引导分流、领取串兑换、自建面板、思想云、轮询/代理/形象/自助更新）。协议见仓库 PROTOCOL.md（v2），许可证 MIT。

验收提示：升级后先看宠物是否照常轮询；打开设置确认顶部是只读展示、无输入框；粘贴一串新配对串点「应用配对串」应自动测连接成功且输入框被清空；粘贴坏串应只提示、现有连接不变。
