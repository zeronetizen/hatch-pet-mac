MusePet Mac 版 v0.24：修引导页标题被裁切、引导页内嵌代理配置行、查名额/兑换失败可见诊断。

1. **修引导页顶部「欢迎使用 MusePet」标题被窗口顶边裁掉一半**：排版计算把窗口整体高度（含标题栏）误当成内容区高度，内容被整体上移了一个标题栏。已按内容区高度正确换算窗口大小，并把顶部留白放宽——品牌区标题、图标、副文案在任何状态（有名额/已满/失败）下都完整显示、不重叠。
2. **引导页新增代理配置行**（状态行下方）：开关 / 类型（HTTP、SOCKS5）/ 主机 / 端口，与设置页是同一份配置、打开即预填已保存值；改完即保存并自动重新查名额。挂代理才能上网的用户，首启在这里从零填上就能查名额，不必先进设置页。每次查询尝试走的是代理还是直连、结果如何，都会写进日志（~/Library/Logs/HatchPet.log），走没走代理从此可核对。
3. **查名额与兑换加韧性**：先走已保存的代理；若没拿到服务器应答且确实走的是代理，自动直连重试一次；两次都失败才显示失败。失败提示恢复诊断细节：主句不变，其后以小字附最终错误（如「（HTTP 503）」或错误域+错误码），方便定位是网络、代理还是服务端问题。兑换成功与业务错误（如码已过期）的行为和文案不变。
4. **其余全部不变**：通道码（`hatchpet1:`）与领取串（`hatchpet-code1:`）格式、已存配置与本机钥文件、更新通道（资产名 HatchPet-mac.zip）都不动，升级不断连、不丢配置。

验收提示：升级后打开引导页，标题应完整可见；代理行应显示与设置页一致的值——把端口改成一个错误值保存，应看到查询失败且小字带错误信息；改回正确值保存，应自动重查出名额状态。
