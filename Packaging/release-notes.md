HatchPet Mac 版 v0.19：兑换改「领取串」单输入，一串粘贴搞定。

1. **领取串兑换**：满员时去 @hatchPetBot 做任务领到的不再是「兑换码 + 数字 ID」两项，而是一串 `hatchpet-code1:` 开头的领取串——把兑换码和你的 Telegram 数字 ID 打包在一起。在引导窗的 bot 面板把整串粘进兑换区、点「兑换」即可：App 会先解码校验（前缀/版本/字段全过才发请求，串不对只提示、不联网），然后自动兑换、连接、落盘。
2. **兑换区简化**：原来的兑换码 + 数字 ID 两个输入框已删掉，兑换区只留领取串一个输入框，不用再对着 bot 消息逐项照抄。服务器侧的码与账号绑定校验不变。
3. **协议文档**：PROTOCOL.md 新增「Claim string」一节（领取串格式、字段、解码校验，以及与配对串的区别：领取串是兑换前凭证、用后即焚；配对串是通道凭证、长期持有）。

其余功能不变（首启引导分流、配对串连接、自建面板、思想云、设置与自助更新）。协议见仓库 PROTOCOL.md（v2），许可证 MIT。

验收提示：满员分流下打开引导窗 → 粘贴一串真实领取串兑换成功自动连接；粘贴改动过/不完整/错前缀的串时只提示不发请求；兑换成功后宠物开始轮询。
