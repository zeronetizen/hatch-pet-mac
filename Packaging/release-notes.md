MusePet Mac 版 v0.29：多对一——一条通道分发给多个 Muse 共同写状态；设置页可直接取当前通道码；导出 skill 按是否已配置通道分流。

1. **设置页显示当前通道码**：「通道连接」节的状态行下方新增一行——只读单行框展示当前通道码整串（由已存的服务器/通道/本机钥文件当场拼出），旁边「复制」按钮一键复制整串（反馈「通道码已复制。」）。主人可以把这串直接分发给自己的其他 Muse，多个 Muse 共用一条通道写状态、宠物跟最后写入的一条走。未配置通道时整行不出现。
2. **导出 skill 附现成通道**：从引导页导出 skill 包（领取包 pet-claim 与自建包 relay-channel-setup 同一规则）时，若 App 已配置通道，包根目录会多一个 `pet-channel.json`（`server_url`/`channel`/`accesskey`/`exported_at`/`note`），把现成通道一起带给接收方；未配置则不附、保持领取版。`accesskey` 只进这个 zip，不进日志。
3. **pet-claim 接收分流**：skill 包里有 `pet-channel.json` 时，接收方 Muse 跳过全部领取步骤，落钥后直接按宠物状态协议写状态（包内新增 `scripts/write.mjs`：读同包配置、走公共中转写接口，只输出 HTTP 状态与 seq、不打印钥）；没有时才走原领取流程。两个 skill 的 SKILL.md 已写明分支判断。

验收提示：已连好通道时打开设置，应在状态行下方看到一整串通道码、点「复制」可粘出整串；此时从引导页导出任一 skill 包，zip 根目录应多出 `pet-channel.json`；把这个包交给另一个 Muse，它应直接用现成通道写状态（宠物随之动），而不是再领一条新通道。
