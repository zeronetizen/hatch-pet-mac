HatchPet Mac 版 v0.13（修复更新检查：避开 GitHub API 限流）。

安装包：HatchPet-mac.zip（解压后右键打开绕过 Gatekeeper）。

本版只修一件事：**更新检查的数据源**。v0.11/v0.12 的检查走 GitHub 的 API 子域，该接口未认证限流按出口 IP 每小时 60 次，经共享代理出口时额度常被别人用满，真机点「检查更新」必报 HTTP 403。v0.13 改走仓库的网页端点 releases.atom（请求失败或解析不到版本时，再用 releases/latest 的跳转目标兜底），不受该限流影响；下载、校验、自动替换、重启等其余更新链路与之前完全一致。

装上 v0.13 后请再点一次「检查更新」：应能发现 v0.14（与本版功能相同的更新通道验证版）并在应用内完成自助更新——这是更新通道的正式首验。

变更细节见仓库 README 的 v0.13 小节。
